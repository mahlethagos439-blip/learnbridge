# LearnBridge — from-zero starter

This is a fresh, standalone responsive website starter built from the provided LearnBridge reference design. It does not reuse the previous ZIP packages.

## Included
- Responsive LearnBridge home screen in blue and yellow
- Left-side hamburger menu with an X close button
- Menu: Home, Exams, Resources, About, My Profile, Settings, Log out
- Bottom navigation: Home, Lessons, Quizzes, Progress, Profile
- Seven subject cards: Mathematics, Physics, Chemistry, Biology, Geography, History, Economics
- No fabricated student counts or success-rate claims
- Notes intentionally not included yet
- Basic navigation feedback for unfinished sections

## Run locally
Open `index.html` in a modern browser. No build tools or internet connection are required.

## Important
This is a front-end starter, not a production-ready learning platform. It has no backend, login, database, admin panel, published notes, exam papers, or quiz bank. Add and test those before presenting it as a fully functioning platform.
